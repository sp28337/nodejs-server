# Node.js Static Server — Learning Project

This repository contains a **minimal Node.js HTTP server** built using the native `http` module.  
The project was created as an early learning exercise to understand how web servers work without frameworks.

The server handles basic routing, serves static files, and resolves MIME types manually.  
The main goal was to explore request handling, file system interaction, and simple project structure.

## Features

- Native Node.js HTTP server (no Express)
- Static file serving (HTML, CSS, JS, images)
- Manual MIME type resolution
- Simple and clear project architecture
